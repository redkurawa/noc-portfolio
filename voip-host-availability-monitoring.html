Project 01 · Monitoring & Incident Detection

VoIP Host Monitoring & WhatsApp Alert Automation

Otomatisasi pemantauan host perangkat klien VoIP menggunakan MikroTik Netwatch yang terintegrasi dengan WhatsApp Gateway. Setiap perubahan status host menjadi DOWN maupun kembali UP dikirim otomatis ke WhatsApp, sehingga tim NOC dapat mengetahui gangguan dan pemulihan tanpa harus terus membuka console MikroTik.

MikroTik RouterOSNetwatchICMP / PingHTTP POSTWhatsApp Gateway

1. Problem — Tantangan Sebelum Otomatisasi

Sebelum notifikasi WhatsApp diterapkan, pemantauan host sangat bergantung pada pengecekan manual melalui console MikroTik. Kondisi ini membuat informasi host DOWN berisiko terlewat, terutama ketika petugas NOC sedang menangani pekerjaan lain.

  1. Akses monitoring tidak praktis: pemeriksaan melalui MikroTik cukup berbelit dan lebih nyaman dilakukan menggunakan PC.
  2. Monitoring bergantung pada operator: petugas NOC tidak selalu membuka console MikroTik setiap saat.
  3. Informasi gangguan berisiko terlambat: host yang DOWN dapat tidak segera diketahui apabila tidak ada pengecekan manual.
  4. Status pemulihan perlu diperiksa kembali: petugas harus mengecek ulang untuk memastikan host sudah UP.

2. Solution — Otomatisasi dengan WhatsApp

MikroTik Netwatch memantau host yang didaftarkan. Script pada event DOWN dan UP mengirimkan pesan melalui HTTP POST ke WhatsApp Gateway. WhatsApp dipilih karena mudah diakses dari smartphone, tidak mengharuskan petugas berada di depan PC, dan memungkinkan pemantauan dari lokasi berbeda.

  1. Daftarkan alamat IP host klien pada Tools → Netwatch.
  2. Pasang script notifikasi pada kolom Down dan Up.
  3. Ketika host DOWN, Netwatch memicu script DOWN dan mengirimkan notifikasi WhatsApp.
  4. Ketika host kembali UP, Netwatch memicu script UP dan mengirimkan notifikasi pemulihan.
  5. Petugas NOC membaca notifikasi dari WhatsApp di smartphone tanpa harus membuka console MikroTik.

Dampak operasional: informasi gangguan dan pemulihan menjadi proaktif, risiko host DOWN terlewat karena tidak sedang membuka console berkurang, dan petugas dapat melakukan triase lebih awal. Waktu respons aktual, jumlah insiden yang sebelumnya terlewat, serta persentase penurunan keterlambatan belum dihitung karena belum tersedia data pembanding.

🎯 Tujuan

Memberikan visibilitas status host klien secara proaktif melalui notifikasi WhatsApp, agar tim NOC dapat mengetahui gangguan maupun pemulihan tanpa harus terus memantau console MikroTik.

🧩 Komponen

  • MikroTik RouterOS dengan fitur Netwatch
  • Daftar alamat IP host klien yang dipantau
  • Script notifikasi UP dan DOWN
  • WhatsApp Gateway dengan endpoint HTTP POST
  • Grup atau nomor penerima notifikasi NOC

Tim NOC
  1. Host klien didaftarkan pada menu Tools → Netwatch di MikroTik.
  2. Netwatch melakukan pemeriksaan konektivitas ke alamat host secara berkala.
  3. Ketika host berubah menjadi DOWN, script DOWN dijalankan untuk mengirim pesan gangguan ke WhatsApp Gateway.
  4. Ketika host kembali UP, script UP dijalankan untuk mengirim pesan pemulihan.

🛠️ Konfigurasi MikroTik Netwatch

Tambahkan setiap host yang ingin dipantau pada Tools → Netwatch. Isi alamat host, interval pemeriksaan, timeout, lalu masukkan script pada kolom Up dan Down.

ParameterFungsi
HostAlamat IP perangkat klien yang akan dipantau.
IntervalJarak waktu antar pemeriksaan Netwatch.
TimeoutBatas waktu menunggu respons ping.
Up ScriptDijalankan ketika host terdeteksi kembali aktif.
Down ScriptDijalankan ketika host terdeteksi tidak dapat dijangkau.

📜 Script Notifikasi UP

Script ini berjalan ketika host kembali merespons. Terdapat jeda lima detik sebelum request dikirim ke WhatsApp Gateway.

🟢 UP — Host kembali normal
:local pesan "$host ASM UP"

:delay 5s
/tool fetch http-header-field="content-type: application/x-www-form-urlencoded" \
    http-method=post \
    http-data="phone=628xxxxxxxxxx&message=$pesan" \
    url="http://10.50.50.101:3000/send/message" \
    keep-result=no;

📜 Script Notifikasi DOWN

Script melakukan pemeriksaan ping ulang sebanyak 60 kali dengan interval satu detik. Notifikasi dikirim apabila pemeriksaan ulang tersebut tidak menerima respons.

🔴 DOWN — Host tidak merespons
:if ([/ping $host interval=1s count=60] = 0) do={
    :local pesan "$host%20ASM%20DOWN"

    /tool fetch \
        http-header-field="content-type: application/x-www-form-urlencoded" \
        http-method=post \
        http-data="phone=628xxxxxxxxxx&message=$pesan" \
        url="http://10.50.50.101:3000/send/message" \
        keep-result=no
}
Catatan privasi: Nomor telepon penerima telah disamarkan. Alamat IP 10.50.50.101:3000 merupakan alamat private WhatsApp Gateway dan dipertahankan sebagai bagian dari dokumentasi arsitektur.

📈 Manfaat Operasional Tambahan

  • Mobilitas: monitoring dapat dilihat dari smartphone tanpa harus berada di depan PC atau workstation NOC.
  • Awareness tim: notifikasi dapat dibagikan pada grup WhatsApp operasional sehingga petugas terkait memperoleh informasi yang sama.
  • Informasi dua arah: status DOWN dan UP membantu petugas membedakan gangguan yang masih berlangsung dengan koneksi yang sudah pulih.
  • Prioritas troubleshooting: alamat host dan waktu notifikasi menjadi petunjuk awal untuk menentukan perangkat atau jalur yang perlu diperiksa.
  • Jejak kejadian: riwayat pesan WhatsApp dapat menjadi referensi awal untuk menelusuri urutan gangguan dan pemulihan.
  • Efisiensi operasional: mengurangi kebutuhan membuka console hanya untuk mengetahui perubahan status host.
  • Proaktif: tim NOC dapat mulai melakukan verifikasi dan koordinasi lebih awal, bukan hanya menunggu laporan dari klien.
