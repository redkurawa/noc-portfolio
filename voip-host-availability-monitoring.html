Project 01 · Monitoring & Incident Detection

VoIP Host Availability Monitoring

Monitoring ketersediaan host perangkat klien VoIP menggunakan MikroTik Netwatch. Ketika host tidak merespons ping, sistem mengirim notifikasi DOWN ke WhatsApp Gateway. Saat host kembali merespons, notifikasi UP dikirim sebagai informasi pemulihan.

MikroTik RouterOSNetwatchICMP / PingHTTP POSTWhatsApp Gateway

🎯 Tujuan

Mengetahui lebih awal apabila perangkat atau jalur jaringan klien mengalami gangguan. Tim NOC memperoleh informasi ketika host tidak dapat dijangkau dan ketika konektivitas kembali normal, sehingga pemeriksaan dapat dilakukan lebih cepat.

🧩 Komponen

  • MikroTik RouterOS dengan fitur Netwatch
  • Daftar alamat IP host klien yang dipantau
  • Script notifikasi UP dan DOWN
  • WhatsApp Gateway dengan endpoint HTTP POST
  • Grup atau nomor penerima notifikasi NOC

Tim NOC
  1. Host klien didaftarkan pada menu Tools → Netwatch di MikroTik.
  2. Netwatch melakukan pemeriksaan konektivitas ke alamat host secara berkala.
  3. Ketika host berubah menjadi DOWN, script DOWN dijalankan untuk mengirim pesan gangguan ke WhatsApp Gateway.
  4. Ketika host kembali UP, script UP dijalankan untuk mengirim pesan pemulihan.

🛠️ Konfigurasi MikroTik Netwatch

Tambahkan setiap host yang ingin dipantau pada Tools → Netwatch. Isi alamat host, interval pemeriksaan, timeout, lalu masukkan script pada kolom Up dan Down.

ParameterFungsi
HostAlamat IP perangkat klien yang akan dipantau.
IntervalJarak waktu antar pemeriksaan Netwatch.
TimeoutBatas waktu menunggu respons ping.
Up ScriptDijalankan ketika host terdeteksi kembali aktif.
Down ScriptDijalankan ketika host terdeteksi tidak dapat dijangkau.

📜 Script Notifikasi UP

Script ini berjalan ketika host kembali merespons. Terdapat jeda lima detik sebelum request dikirim ke WhatsApp Gateway.

🟢 UP — Host kembali normal
:local pesan "$host ASM UP"

:delay 5s
/tool fetch http-header-field="content-type: application/x-www-form-urlencoded" \
    http-method=post \
    http-data="phone=628xxxxxxxxxx&message=$pesan" \
    url="http://10.50.50.101:3000/send/message" \
    keep-result=no;

📜 Script Notifikasi DOWN

Script melakukan pemeriksaan ping ulang sebanyak 60 kali dengan interval satu detik. Notifikasi dikirim apabila pemeriksaan ulang tersebut tidak menerima respons.

🔴 DOWN — Host tidak merespons
:if ([/ping $host interval=1s count=60] = 0) do={
    :local pesan "$host%20ASM%20DOWN"

    /tool fetch \
        http-header-field="content-type: application/x-www-form-urlencoded" \
        http-method=post \
        http-data="phone=628xxxxxxxxxx&message=$pesan" \
        url="http://10.50.50.101:3000/send/message" \
        keep-result=no
}
Catatan privasi: Nomor telepon penerima telah disamarkan. Alamat IP 10.50.50.101:3000 merupakan alamat private WhatsApp Gateway dan dipertahankan sebagai bagian dari dokumentasi arsitektur.

📲 Contoh Notifikasi WhatsApp

Pesan yang diterima tim NOC memuat alamat host dan statusnya. Contoh berikut menggunakan identitas host dan klien samaran.

🔴 Host DOWN

HOST-XXX.XXX.XXX.XX CLIENT-A DOWN

Menandakan host tidak merespons pemeriksaan konektivitas.

🟢 Host UP

HOST-XXX.XXX.XXX.XX CLIENT-A UP

Menandakan host kembali dapat dijangkau.

📈 Hasil dan Manfaat Operasional

  • Gangguan konektivitas host dapat diketahui secara proaktif melalui notifikasi otomatis.
  • Tim NOC memperoleh informasi waktu kejadian DOWN dan pemulihan UP.
  • Pemeriksaan awal dapat diarahkan ke host atau jalur jaringan yang terdampak.
  • Notifikasi mengurangi ketergantungan pada laporan awal dari pengguna klien.
